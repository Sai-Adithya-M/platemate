Open Source Implementation

Technical architecture, model implementation, and offline-first execution details.

Where are the open source components located?

The system is contained directly in this repository without any cloud API wrapper:

  • Runtime: @xenova/transformers (Hugging Face Transformers in WebAssembly) is imported in index.html.
  • Local Weights: Open-weight models (e.g. distilbert-base-uncased) are cached in the browser's CacheStorage for local execution.
  • Derivative Taxonomy: app.js houses an open taxonomy mapping over 100 biochemical derivative terms (spelt, kamut, farro, maltodextrin, caseinate, praline, etc.).
  • License: Licensed under Apache 2.0.
Why an offline open-source design instead of a cloud API?

Key technical and practical constraints:

  • Connectivity: Grocery stores and basements frequently lack mobile data. Client-side WebAssembly execution operates without an internet connection.
  • Privacy: Dietary and autoimmune records are private health data. Processing locally keeps data within the browser sandbox.
  • Cost & Availability: Eliminates subscription requirements and token rate limits.
