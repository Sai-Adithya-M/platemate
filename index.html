Where is the Open Source AI kept in this project?

Here is an honest, clear breakdown of every open-source component powering PlateMate and why it matters.

1. Where are the open-source AI models & libraries located?

Everything runs directly in this codebase without any private proprietary backend:

  • Open Model Engine: We use Transformers.js (Hugging Face) imported directly in index.html (line 12). It runs open-weight ONNX models inside the user's browser using WebAssembly.
  • Local Inference Weights: The model runs quantized open-weight NLP pipelines (like Xenova/distilbert-base-uncased) downloaded to the browser's local CacheStorage. Once loaded once, it works forever completely offline with zero internet.
  • Open Biochemical Ontology: In app.js (lines 8–80), we built an open, auditable knowledge tree mapping over 100 hidden chemical food derivatives (like malted barley, spelt, kamut, caseinate, praline).
  • Open Codebase License: 100% of this project is licensed under Apache 2.0 and hosted in this local repository.
2. Why couldn't I just use ChatGPT / OpenAI API?

Three real-world reasons why a closed cloud API actually fails Elena:

  • Supermarkets have zero reception: Elena shops at Trader Joe's in a basement. Closed APIs fail with a 504 timeout when you have no signal. PlateMate runs 100% locally on airplane mode.
  • Medical privacy: Elena's chronic health conditions shouldn't be logged on a corporate server to build advertising profiles.
  • Zero cost forever: People with Celiac disease already pay 3x more for groceries. Safety tools should be free open utilities, not monthly subscriptions.
